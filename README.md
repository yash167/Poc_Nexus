## 🔥 What Is PoC Nexus ?

PoCForge is a next-generation cybersecurity intelligence platform that transforms raw vulnerability data into predictive risk insights, adversarial modeling simulations, and board-level intelligence.

It doesn’t just tell you what is vulnerable.  
It tells you:

- 🎯 What is most likely to be exploited  
- ⚠️ What could become a zero-day  
- 💣 How an attack chain could unfold  
- 💰 What the financial blast radius would be  
- 📊 What your executive team needs to know  

---

# 🧠 Why PoC Nexus?

Traditional vulnerability tools focus on scanning.

PoCForge focuses on:

### ✅ Prediction  
Machine learning–driven zero-day probability estimation.

### ✅ Prioritization  
Risk scoring based on CVSS, EPSS, exposure, exploit maturity, and business impact.

### ✅ Adversarial Modeling  
Safe attack-chain simulation mapped to MITRE ATT&CK.

### ✅ Executive Translation  
Board-ready summaries with SLA forecasting and financial exposure estimates.

# 🚀 Quick Start

### Run with Docker

```bash
cd docker
docker-compose up --build
```

Visit:

```
http://localhost:8000/health
```

---

### Run Frontend

```bash
cd frontend
npm install
npm run dev
```

Visit:

```
http://localhost:5173
```
